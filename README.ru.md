# Still Alive · Unity 6

[English](README.md) · [Русский](README.ru.md)

Мне захотелось поиграть с паркуром Mirror's Edge и делать свои карты в редакторе. Я нашёл [Still Alive от Eideren](https://github.com/Eideren/Mirror-s-Edge), запустил его в Unity и залип. Этот форк появился из желания продолжить работу с тем, что он сделал.

**Автор исходного порта - Eideren.** Без его работы этого проекта бы не было. Огромное ему спасибо.

Теперь проект работает на Unity 6. Пока я хочу заниматься бегом, прыжками, захватом, раскачиванием, камерой и анимациями. Боёвку, AI, сюжетные события, меню и сохранения сейчас не планирую. Это некоммерческий эксперимент: баги ещё есть, а обновления будут появляться по мере работы.

## Немного истории

Eideren начал репозиторий в 2021 году, а позже перевёл его на Unity 2022.3. В статье [Mirror's Edge Decompiled](https://eideren.com/posts/mirrors-edge-decompiled.html) он рассказывает, как изучал движение в игре: переводил UnrealScript в C# через Unreal Library и восстанавливал поведение нативного кода с помощью дизассемблера и отладчика. Ввод, отрисовку, физические запросы и воспроизведение звука взяла на себя Unity. Состояния движения, анимации и игровая логика работают через перенесённый код.

Главной темой его работы были персонаж и паркур. Он также писал о недоработанном звуке и проблемах со ступеньками и склонами. Я продолжаю эту работу и сохраняю оставшиеся задачи в [TODO.md](TODO.md). Вот [демонстрация его исходного проекта](https://www.youtube.com/watch?v=W6-_Lgdt0zg).

За этот форк я взялся в октябре 2026 года. Пока основные изменения - исправления движения и небольшая карта, на которой проще пробовать паркур.

## Как попробовать

Нужны **Unity 6000.6.4f1**, Git и **Git LFS**. Это конкретная версия Unity 6, на которой всё проверялось; другие пока не проверял. Проект использует Built-in Render Pipeline. Проверки выполнялись на Windows.

Скачивай через Git. **Download ZIP лучше не использовать**: вместо моделей и текстур в нём могут оказаться указатели LFS.

```sh
git lfs install
git clone https://github.com/yamixdev/Mirror-s-Edge.git
cd Mirror-s-Edge
git lfs pull
```

Открой папку в Unity Hub через **6000.6.4f1**, дождись импорта, затем открой **`Assets/New Scene.unity`** и нажми Play. Кликни по окну Game, чтобы управлять Фэйт.

Я добавил эту маленькую тестовую карту, чтобы можно было сразу попробовать. Там есть препятствия, Spawn, балка для баланса, перекладина, лестница и трос. Полная модель Фэйт и восстановленные текстуры тоже включены. Большая исходная карта осталась в `Assets/Scenes/Cranes_Off.unity`; её я ещё не проверил целиком.

| Управление | Действие |
| --- | --- |
| W / A / S / D | Движение; W / S также отвечают за подъём и раскачивание |
| Мышь | Обзор |
| Пробел | Прыжок, подъём с уступа, прыжок с перекладины |
| Левый Shift | Приседание / скольжение или отпускание объекта при висе |
| Q | Быстрый разворот / взгляд назад |

Для своей карты добавь пол с коллайдерами, Main Camera, Directional Light и **`Assets/Spawn.prefab`**. Вокруг Spawn оставь место для тела. Объекты паркура бери из **`Assets/Prefabs/Parkour`**. Как их ставить и менять размеры, описано в [инструкции](docs/parkour-objects-ru.md).

Visual Studio и Unity MCP для игры в редакторе не нужны.

## Что уже изменилось

- Исправлены проверенные случаи дрожания у стен, исчезновения рук у уступов и смещения назад при подъёме.
- Убрана отложенная смерть после прыжка, исправлено залипание запроса приседа.
- Доработаны раскачивание, переходы между перекладинами, боковое движение рук и его звуки.
- Добавлены готовые объекты паркура. Удержание пробела при vault с опорой на одну левую руку теперь даёт один прыжок вверх с сохранением скорости вперёд.
- Включено целое тело для Scene, внешних камер и теней. Игровая камера сохраняет исходные модели от первого лица; отдельного режима игры от третьего лица это не добавляет.

Подробности - в [CHANGELOG.md](CHANGELOG.md). [Проверки](Tools/CollisionProbe/README.ru.md) запускаются в отдельном проекте Unity.

## Что ещё надо поправить

Захват лестницы может выдавать ошибку. Руки полной модели местами всё ещё стоят криво. Нужно разобраться со склонами, застреваниями, сообщениями об отсутствующих анимациях и работой на разной частоте кадров. Полный список, включая старые задачи Eideren, находится в [TODO.md](TODO.md).

Полная отдельная сборка, все карты, URP/HDRP и другие платформы пока не проверены. Если найдёшь баг, создай issue: укажи версию Unity, сцену, нажатые кнопки и как повторить проблему. Нужная ошибка из Console со стеком вызовов тоже поможет.

Если нет моделей или текстур, проверь, что `git lfs pull` завершается успешно. В исходном README также было [зеркало ассетов](https://mega.nz/folder/48hnGBTY#jIfGg36zOBKYF1eVuT71sQ); там файлы оригинального проекта, а не новые файлы этого форка.
