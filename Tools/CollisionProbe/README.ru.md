# Проверка столкновений персонажа

Из корня проекта в PowerShell:

```powershell
& ./Tools/CollisionProbe/Invoke-CollisionProbe.ps1
```

Скрипт создаёт отдельный проект в `Documents/MirrorEdgeParkourData/CollisionProbeProject`, копирует текущие C#-исходники, определения сборок, пакеты и настройки компиляции. Версия Unity берётся из `ProjectSettings/ProjectVersion.txt`; другой путь можно передать через `-UnityExe`.

Открытая сцена основного проекта не используется. Тест запускается в отдельном Unity через `-batchmode -nographics -executeMethod CollisionProbe.Run`. Сценовые и художественные ассеты не копируются. Кэш Library сохраняется для следующих запусков. Существующая папка без маркера `.collision-probe-owned` не перезаписывается.

Проверяются настоящие `UWorld.MultiLineCheck`, `UWorld.MoveActor` и `TdPawn.stepUp` с физикой Unity. Стенка, пол и низкая ступенька создаются из простых коллайдеров; отдельная проверка использует MeshCollider. Для запуска без звуков и графики тест заранее помещает пустой материал Concrete в кэш материалов. Физические запросы и код шага не подменяются.

В `RepeatedBlockedStepsKeepHeight` настоящая функция шага вызывается после блокировки движения 120 раз. Проверяется отсутствие накопленного подъёма. В `LowStepRemainsClimbable` проверяется сохранение подъёма на ступеньку 20 см.

Результат: `Evidence/collision-final.json` в отдельном проекте. Скрипт завершает работу с ошибкой при провале проверки, ошибке компиляции или таймауте. Полный лог остаётся локально: он может содержать аргументы лицензирования Unity, поэтому не публикуйте его целиком.

Эти проверки не запускают полный цикл ввода, анимации и камеры. После изменения нужно отдельно проверить удержание W, скольжение вдоль стены и обычный паркур в своей карте.

## Проверки исправлений из ревью

```powershell
& ./Tools/CollisionProbe/Invoke-CollisionProbe.ps1 -EntryPoint ReviewProbe.Run -ReportName review-final
```

`ReviewProbe` входит в Play Mode только в отдельном тестовом редакторе. Это необходимо для реальных вызовов `OnDestroy` у обычных MonoBehaviour. Проверяется удаление паркур-объектов, включая удаление внутри обновления мира; конечные позы обычного и импортированного зацикленного клипа; очистка и восстановление графов анимации; Raycast и BoxCast с 16, 17, 65 и 129 коллайдерами; Overlap с 65 коллайдерами.

Отдельный проект компилирует текущие исходники основного проекта. Результат сохраняется в `Evidence/review-final.json`. Основной редактор этот запуск не переводит в Play Mode.

## Руки при захвате края

```powershell
& ./Tools/CollisionProbe/Invoke-CollisionProbe.ps1 -EntryPoint GameplayHandsProbe.Run -ReportName hands-final
```

Для этой проверки в отдельный проект копируются `Assets/Source/Resources` и настройки ввода. Unity запускается с графикой в скрытом окне; нужен рабочий графический адаптер. Основная сцена и ввод пользователя не используются.

Тест создаёт стену, пол и Spawn, запускает настоящий `UWorld` и переводит Faith в `MOVE_Grabbing`. Проверяются шесть сочетаний наклона и поворота камеры. Изображение модели сравнивается с той же позой, запечённой через `BakeMesh` в обычный MeshRenderer: так устаревшие границы SkinnedMeshRenderer не могут скрыть ошибку в эталоне. Цвет модели временно красный только в тестовом проекте для подсчёта пикселей. Сохраняются JSON, PNG и координаты камеры/рук в `Evidence`.

Это проверяет исчезновение рук при захвате и повороте камеры. Полный проход всех движений на пользовательской карте в эту проверку не входит.

## Остальные проверки

[English](README.md) · [Русский](README.ru.md)

Для каждого запуска меняй `-EntryPoint` и `-ReportName`:

| EntryPoint | Что проверяется |
| --- | --- |
| PullUpProbe.Run | Путь подъёма с уступа, завершение, присед под потолком и заблокированный путь |
| VaultJumpProbe.Run | Удержанный и отпущенный пробел после vault, один толчок, скорость и потолок |
| ParkourObjectsProbe.Run | Геометрия префабов, зоны взаимодействия, размеры и регистрация в мире |
| JumpSurvivalProbe.Run | Отсутствие смерти от старого колбэка прыжка после задержки |
| SwingProbe.Run | Захват, границы перекладины, перенос скорости, переходы между перекладинами, звук и восстановление ввода |
| ShimmyProbe.Run | Контакт рук, фазы отпускания и захвата, звуковые события при обратном воспроизведении и очистка |
| FullBodyProbe.Run | Материалы, масштаб, полная модель, видимость для игровой камеры, тени и вложенная отрисовка камер |

```powershell
& ./Tools/CollisionProbe/Invoke-CollisionProbe.ps1 -EntryPoint FullBodyProbe.Run -ReportName fullbody
```

Для этих проверок нужен графический адаптер. Импортированные анимации, материалы и текстуры должны быть скачаны через Git LFS. Дополнительные ассеты персонажа и префабы копируются в отдельный проект; пользовательская сцена не используется.

Другую установку редактора можно задать через `-UnityExe`, отдельную папку проверки - через `-ProbeProject`. Если удаляешь или переименовываешь исходники, выбирай новую папку `-ProbeProject`, чтобы старые скопированные файлы не влияли на результат.

`PublishedSceneProbe.Run` проверяет переносимую тестовую карту: Spawn, камеру и свет, скрипты, зависимости базовых материалов, запуск живого персонажа и включённые текстуры тела. Открывается только копия `New Scene` в отдельном проекте. В опубликованной сцене базовые материалы; изменённой локальной карте могут понадобиться другие ассеты.
